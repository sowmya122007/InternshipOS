# InternshipOS

> A student-focused internship discovery platform that helps users explore companies by city and access their official career pages.

## ✨ Features

- 🌆 Explore major technology cities
- 🏢 Discover companies by location
- 🔍 Search companies within a city
- 💼 Explore internship-relevant career areas
- 🏷️ View company profiles and key information
- 🔗 Direct access to official company career pages
- 📱 Responsive and modern user interface
- 🧭 Simple step-by-step internship discovery flow

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
InternshipOS/
└── index.html
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.

## 🎯 Motivation

Students often know a few major companies such as Google, Microsoft, or Amazon, but may not know about the many other companies operating across India's major technology hubs.

InternshipOS was created to make that discovery process simpler.

The idea came from noticing how many technology companies are present across Hyderabad's IT corridor and thinking:

> **What if students could choose a city, explore the companies there, understand what each company does, and go directly to its official career page from one place?**

InternshipOS turns that idea into a simple, student-friendly discovery experience.
